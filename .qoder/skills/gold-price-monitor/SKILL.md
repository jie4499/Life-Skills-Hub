## 使用方法

黄金价格监控技能，通过招商银行API获取实时黄金价格，结合华尔街见闻新闻进行分析。

### 功能特性

1. **实时价格获取**
   - 通过招商银行API获取实时黄金价格
   - 每分钟自动查询一次

2. **价格曲率分析**
   - 计算价格上涨/下跌曲率
   - 计算平均价格变化曲率
   - 当曲率偏离平均值时触发预警

3. **新闻分析**
   - 获取华尔街见闻热门文章
   - 分析新闻内容对黄金价格的影响
   - 生成投资建议

### 数据来源

- **黄金价格**: https://m.cmbchina.com/api/rate/gold
- **新闻资讯**: https://api-one-wscn.awtmt.com/apiv1/content/articles/hot?period=all

### 使用方式

启动监控服务：

```bash
python scripts/gold_monitor.py --interval 5 --threshold 2.0
```

**参数说明**:
- `--interval`: 查询间隔（秒），默认 60 秒（1分钟）
- `--threshold`: 曲率预警阈值，默认 2.0（标准差倍数）
- `--window`: 计算平均曲率的时间窗口（数据点数），默认 20

**示例**:
```bash
# 默认配置运行
python scripts/gold_monitor.py

# 自定义配置：每30秒查询一次，曲率阈值1.5
python scripts/gold_monitor.py --interval 30 --threshold 1.5 --window 30
```

### 预警规则

1. **曲率计算**: 使用二阶导数近似计算价格变化加速度
2. **平均曲率**: 基于滑动窗口计算历史平均曲率
3. **预警触发**: 当 |当前曲率 - 平均曲率| > threshold × 标准差 时触发

### 注意事项

1. **API限制**: 招商银行API可能有访问频率限制，请合理设置查询间隔
2. **数据准确性**: 价格数据仅供参考，实际交易请以银行报价为准
3. **投资风险**: 投资建议基于算法分析，不构成实际投资建议
4. **网络依赖**: 需要稳定的网络连接获取实时数据
